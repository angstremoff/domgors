# 📋 Обзор проекта DomGoMobile

Приложение для поиска и размещения объявлений о недвижимости (Сербия, `domgo.rs`).

## Целевая аудитория
- Покупатели/арендаторы недвижимости
- Продавцы и арендодатели
- Риелторы и агентства

## Функциональность
- 🔍 Поиск с фильтрами: тип сделки (продажа/аренда), категория (квартира/дом/коммерческая/земля), цена, площадь, комнаты, город, район; новостройки как отдельная категория (только продажа)
- 📝 CRUD объявлений с загрузкой фото (до 20)
- 👤 Профили пользователей и агентств, контакты централизованы в `public.users`
- ❤️ Избранное
- 🗺️ Карта с геолокацией
- 🌍 Мультиязычность: 🇷🇺 русский, 🇷🇸 сербский
- 🔐 Auth: email+password (Supabase); deep links `domgomobile://`

## Жизненный цикл объявления
```
Создание → Активно → Продано/Сдано (status: active/sold/rented)
```

## Платформы
- **Mobile:** React Native (Android: Google Play + RuStore, iOS)
- **Web:** `domgo.rs` (Next.js static export) — уже работает
- **Admin:** `/admin` (Next.js)

## Планы развития
- Push-уведомления, аналитика рынка, ИИ-рекомендации, встроенный чат

## Конкурентные преимущества
Современный стек (RN + Supabase), мультиязычность, единый репозиторий для mobile/web/admin.
